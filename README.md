# Career Compass

Career Compass is a desktop-first Next.js prototype for evidence-based career discovery.

It helps students:

- Complete a structured Career Discovery assessment
- Generate a weighted career profile from question-bank answers
- Review specific career path recommendations and skill gaps
- Explore company-style simulations with provided logo assets
- Follow a personalized 30-day, 90-day, and 12-month roadmap

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Validation

```bash
npm run lint
npm run build
```

## Deployment

The app is ready to deploy as a standard Next.js project on Vercel.
